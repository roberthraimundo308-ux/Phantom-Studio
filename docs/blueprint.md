# **App Name**: Phantom Studio

## Core Features:

- Hero Section Display: A visually engaging full-screen hero area with dynamic text and an animated dot-grid background effect.
- Service Offerings Showcase: An interactive list of services offered, where clicking reveals detailed descriptions and associated keywords/technologies.
- Expandable Project Portfolio: A grid-based portfolio of projects where individual items expand to reveal a site mockup, description, and link to the live project.
- Service Value Comparison: A dedicated section highlighting the qualitative and quantitative benefits of the studio's services compared to common alternatives.
- AI-Powered Project Description Assistant: A tool to assist in generating compelling and creative descriptive copy for new portfolio entries or case studies, based on user-provided keywords and project brief.
- Progressive Scroll Navigation: A dynamic sidebar navigation element that tracks the user's scroll position and allows for smooth jumping between main content sections.
- Animated Performance Metrics: Interactive animated counters and filling progress bars that visually represent key company achievements and reliability metrics.

## Style Guidelines:

- Schema de cores escura com fundo preto suave (#050505) para um visual moderno e sofisticado. A cor principal para textos e elementos-chave é um branco-acinzentado quente (#EDE8DE) para garantir alta legibilidade. Um verde limão vibrante (#C8FF00) é usado como cor de destaque para elementos interativos e detalhes, proporcionando energia e um toque de alta tecnologia.
- Fontes: Para títulos e elementos de destaque, recomenda-se 'Bebas Neue' (sans-serif) por sua presença impactante. Para o corpo do texto e a maioria dos elementos da interface, a fonte 'Syne' (sans-serif) oferece uma estética limpa e moderna. Para texto tipo código e rótulos específicos, 'DM Mono' (monospace) proporciona clareza e um estilo técnico.
- Ícones: Utilização de ícones geométricos e monocromáticos, alinhados com a paleta de cores. Símbolos simples de marcação (como '✕' e '✓') para listas e setas sutis para navegação e botões, que podem girar ou mudar de cor em estados de hover para adicionar interatividade.
- Disposição Visual: Um layout limpo e expansivo, utilizando abundantemente 'espaço negativo' (cores escuras de fundo) para destacar o conteúdo. A navegação é fixa no topo e um indicador de progresso de seção fixo à esquerda para uma experiência fluida. O portfólio utiliza um sistema de cartão expansível para detalhes. Há uso predominante de CSS Grid e Flexbox para garantir responsividade em diversas telas.
- Animações: Efeitos de 'scroll-reveal' suaves e com 'stagger-delay' para que os elementos apareçam gradualmente à medida que o usuário rola. Animações sutis em botões (transformação de escala/translação, mudança de gap) e barras de progresso que se preenchem dinamicamente. Efeitos de paralaxe e textura 'grain' para profundidade visual no fundo do hero. Um cursor personalizado para adicionar um toque de interatividade única.
